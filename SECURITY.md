# Security Policy

Please do not publish real server credentials, Discord tokens, FTP passwords, session secrets, IPs, or production `.env` files in issues, pull requests, screenshots, or commits.

If you find a vulnerability, report it privately to the repository owner instead of opening a public issue.

## Sensitive data checklist

Before publishing or sharing this project, verify that the following files are not committed:

- `.env`
- runtime SQLite databases
- server backups
- FTP cache files
- logs
- Discord bot tokens
- Palworld admin passwords
- GPORTAL/Nitrado credentials
